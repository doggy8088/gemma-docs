# Gemma Documentation

Gemma is a family of open generative AI models by Google DeepMind. You can use them for question answering, summarization, reasoning, and more. Gemma models are provided with open weights and permit responsible commercial use.

## Gemma 4

The latest generation featuring four distinct architectures:

- **Small Sizes (E2B, E4B):** Effective parameter models built for ultra-mobile, edge, and browser deployment.
- **Dense (31B):** A powerful dense model bridging server-grade performance and local execution.
- **Mixture-of-Experts (26B A4B):** A highly efficient MoE model designed for high-throughput, advanced reasoning.
- **Unified (12B):** An encoder-free model for multimodal tasks using direct linear projections.

## Key Capabilities

- **Reasoning:** Highly capable reasoners with configurable thinking modes.
- **Multimodal:** Processes text, images, video, and audio.
- **128K–256K Context Windows:** Small models feature 128K, medium models support 256K.
- **Function Calling:** Built-in support for structured tool use and autonomous agents.
- **Multi-Token Prediction:** All Gemma 4 models include a dedicated draft model for speculative decoding.
