# Gemma 禁止使用政策

Google 保留隨時更新本 Gemma 禁止使用政策的權利。

最後修改日期：2024 年 2 月 21 日

您**不得**將 Gemma 或模型衍生作品（Model Derivatives）用於以下用途，亦不得允許他人將其用於以下用途：

1. 產生任何侵害、盜用或以其他方式違反任何個人或實體權利的內容，包括 Gemma 或模型衍生作品產生的輸出或結果（包括但不限於受版權保護內容的權利）。
2. 從事或促成危險、非法或惡意的活動，包括：
    1. 促成或宣傳非法活動或違法行為，例如：
        1. 宣傳或產生與兒童性虐待或性剝削相關的內容；
        2. 宣傳或促成非法物質、商品或服務的販售，或提供合成或取得這些物品的指示；
        3. 促成或鼓勵使用者犯下任何類型的罪行；或
        4. 宣傳或產生暴力極端主義或恐怖主義內容。
    2. 從事任何職業或專業的非法或無照執業，包括但不限於法律、醫療、會計或金融專業實務。
    3. 濫用、傷害、干擾或破壞服務（或使他人能夠為之），例如：
        1. 宣傳或促成垃圾訊息的產生或散佈；或
        2. 為欺騙或詐欺活動、詐騙、網路釣魚或惡意軟體產生內容。
    4. 試圖規避或繞過安全過濾機制，或故意驅使 Gemma 或模型衍生作品以違反本 Gemma 禁止使用政策的方式運作。
    5. 產生可能傷害個人或群體，或鼓吹傷害個人或群體的內容，例如：
        1. 產生宣傳或鼓勵仇恨的內容；
        2. 提供騷擾或霸凌的方法，以恐嚇、虐待或侮辱他人；
        3. 產生促成、宣傳或煽動暴力的內容；
        4. 產生促成、宣傳或鼓勵自殘的內容；
        5. 產生個人可識別資訊以供散佈或造成其他傷害；
        6. 未經他人同意追蹤或監控他人；
        7. 產生可能對他人造成不公平或不利影響的內容，特別是與敏感或受保護特徵相關的影響；或
        8. 未取得適用法律要求的所有權利、授權與同意，即產生、蒐集、處理或推斷個人的敏感個人或私人資訊。
3. 產生並散佈意圖誤導、歪曲或欺騙的內容，包括：
    1. 聲稱內容由人類創作，或將生成內容表述為原創作品以達到欺騙目的，對生成內容的來源作出不實陳述；
    2. 產生冒充個人（在世或已故）且未明確揭露的內容，以達到欺騙目的；
    3. 在敏感領域（例如健康、金融、政府服務或法律）作出誤導性的專業或能力宣稱；
    4. 在影響重大權益或個人權利或福祉的領域（例如金融、法律、就業、醫療、住房、保險與社會福利）作出自動化決策；
    5. 產生誹謗性內容，包括誹謗性陳述、圖像或音訊內容；或
    6. 從事任何專業的未經授權或無照執業，包括但不限於金融、法律、醫療／健康或相關專業實務。
4. 產生性露骨內容，包括為色情或性滿足目的而創作的內容（例如性聊天機器人）。請注意，這不包括為科學、教育、紀實或藝術目的而創作的內容。
